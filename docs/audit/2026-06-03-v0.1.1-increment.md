## 2. 干净项（正向比对，无发现）

- **prefs anti-poisoning**：fontSize 必落预设档位、showLineNumbers 必 boolean、JSON 损坏/localStorage 不可用全量回默认 → 校验完整
- **api 对齐**：`EditorPrefsAPI`（fontSize/showLineNumbers/increase/decrease/toggle）与 api-spec §3.1 增补块一致；M4 删 getRootElement 后 §3.2/5.5 同步无残留
- **security**：新代码零 innerHTML（toast 用 `textContent`，gutter 用 `<For>`+文本节点）；唯一 innerHTML 仍是 M2 preview（DOMPurify，未动）；prefs localStorage 有校验 → 无新增注入面
- **architecture-constraints**：魔法值全常量化（FONT_SIZE_PRESETS / DEFAULT_MS / LEAVE_MS）；type 字段用 union（ToastLevel）非魔法串；代码无中文串（按钮 "A−"/"A+"/"#" 是符号，中文仅在 i18n dict — 合规）
- **i18n**：3 新 key 同步 dict + EXPECTED_KEYS 白名单，测试强制
