## 2. 干净项（正向比对）—— 安全是重点

- **XSS 面最小化（降风险路径奏效）**：KaTeX `output:'html'`（仅 styled span，**无 MathML/SVG** → 避开 MathML/`foreignObject` 高发向量）+ `trust:false`（`\href{javascript:}` 被中和为错误文本）+ **render 不放宽 DOMPurify allowlist**（styled span 过默认 sanitize 即存活，零新增放行面）。三重降风险叠加，AC-v13-3 发布门槛达成
- **XSS 测试 DOM 级**：katex.test 用 DOMParser 查真实元素/属性（非字符串），避开"katex-error title 回显恶意输入"的误报；ac8-katex E2E-v13-003 alert spy + script/onerror/js-href 计数（双引擎）
- **异步无竞态**：load 后 memo 重算读**当前** text（非闭包旧值）→ 文本加载期间变更不串；ensureKatex memoized 单次加载
- **懒加载守首屏**：katex JS ~80KB 在 lazy chunk，**不进首屏**（index.html 不引用）；首屏 76.66KB gz < 150
- **size 闸修正**：原版 sum 整个 dist（含 lazy chunk）→ 代码分割后会误判；改为按 index.html 引用集算首屏 → 正确（顺带修了一个 latent 缺陷：任何代码分割都会让旧闸误算）
- **非公式 `$`**：hasMath 贴近 katex 规则（闭 `$` 后非数字）→ "$5 和 $10" 不触发；非法 LaTeX throwOnError:false 不崩

## 3. 发现（全 LOW）

| 编号 | 单元 | 描述 | severity |
|------|------|------|---------|
| F-V13-1 | vite.config / 懒加载 | **katex CSS 未懒加载**：`cssCodeSplit:false` 把动态 import 的 katex CSS 打进首屏单一 style.css（首屏 CSS 1.7→9.48KB gz）。偏离 TBD-v13-4"CSS 懒加载"；首屏 76.66KB <150 → 非阻塞。修需翻 cssCodeSplit:true（影响全局 CSS 策略）| LOW |
| F-V13-2 | `hasMath` | 启发式正则 ≠ katex 真 tokenizer。理论上存在 hasMath **漏判**真公式（如转义 `\$` / 边界组合）→ katex 永不加载 → 公式卡在 raw。常见用例已测覆盖，exotic 边界未穷举 | LOW |
| F-V13-3 | size 闸语义变更 | 闸从"全 dist"改"首屏"是正确修正，但**语义变了**：现在不防"lazy chunk 无限膨胀"（katex chunk 多大都不计首屏闸）。若未来 lazy chunk 失控无人察觉。建议补一个 total-dist 软上限提示（非硬闸）| LOW |

## 4. 盲点声明

- **XSS 仅测了已知向量**（\href js / onerror img / script / iframe / 非法 latex）——未做模糊测试 / 未穷举 katex 所有命令的注入面。output:'html'+trust:false+默认 DOMPurify 三重防护使残余面很小，但"未发现 = 不存在"不成立
- **未真机验隐私模式 / 各浏览器 katex 渲染**；e2e chromium+webkit
- F-V13-2 漏判是推断（未构造出实际漏判的公式）
- 自审自己代码

## 5. 结论

v1.3 增量**无 critical/high/medium**。安全敏感面（放行渲染输出）经**降风险路径**（KaTeX-only + output:html + trust:false + 不放宽 sanitize）处理得当，AC-v13-3 发布门槛达成。3 条 LOW（katex CSS eager / hasMath 启发式 / size 闸语义）deferred，不阻塞 tag v0.4.0。
