## 1. 范围与方法

增量（`git diff d612431..a32f43b -- src/`）：`m2-preview/pipeline.ts`（mermaid fence + 懒加载 + renderMermaid sanitize）/ `PreviewArea.tsx`（异步编排 + 代次令牌）+ mermaid 单测 + ac9 e2e。
方法：逐文件重读 + 对齐 共识 v1.4 / ADR-008 / **ADR-002 sanitize 红线** / 安全，对抗视角找 SVG XSS / 异步竞态 / 降级。

## 2. 干净项（正向比对）—— 安全重点

- **SVG XSS 三层防御 + e2e 门槛达成**：mermaid `securityLevel:strict` + `htmlLabels:false`（砍 foreignObject）+ DOMPurify svg profile + 显式 `FORBID_TAGS:[foreignObject,script]`。E2E-v14-003 **双引擎**确认恶意 mermaid（label 注入 img onerror / script）→ 无 alert / 0 script / **0 foreignObject** / 0 onerror。AC-v14-3 发布门槛达成
- **懒加载守首屏**：mermaid 581KB→135KB gz 独立 lazy chunk，**不进首屏**；首屏 77.34KB <150（mermaid+katex 双懒加载均排除——**靠 v1.3 修正的首屏 size 闸**，否则总 dist ~290KB 会硬失败）
- **竞态保护**：代次令牌（每次 text 变 gen++，异步渲染完成 gen≠myGen 则丢弃）→ 不串图
- **失败降级**：单块 try/catch → mermaid-error 占位，不连累其余 markdown（E2E-v14-004 验证 h1 仍渲染）
- **占位健壮**：源文存 textContent（过 sanitize 更稳）而非 data-*（实测 data-* 被默认 DOMPurify 剥离）

## 3. 发现（全 LOW）

## 4. 盲点声明

- **SVG XSS 仅测已知向量**（label img/script 注入）——未穷举 mermaid 所有图类型 / `%%{init}%%` 指令 / `click` 指令（strict 应禁）的注入面；三层防御使残余面小，但"未测尽 = 未证无"
- **renderMermaid 真渲染无单测**（jsdom 限制，PP-003 家族）——全靠 e2e；这是 mermaid 的固有测试约束
- F-V14-1 perf 未实测大文档多图快速打字的实际卡顿
- 自审自己代码（最高风险版尤需第二人，无）

## 5. 结论

v1.4 增量**无 critical/high/medium**。最高风险版（SVG/foreignObject + 异步 + 竞态）经**降风险路径**（strict + htmlLabels:false 砍 foreignObject + 三层 sanitize）+ **e2e 双引擎 XSS 门槛**处理得当，AC-v14-3 达成（foreignObject count 0 实证 FORBID 生效）。3 条 LOW（重渲染 perf / XSS 仅 e2e / 主题切换不重渲染）deferred，不阻塞 tag v0.5.0。

**跨版本一致性**：v1.3"先降风险面再实现"的模式在 v1.4 延续（strict+htmlLabels:false 类比 KaTeX output:html）；v1.3 修的首屏 size 闸在 v1.4（mermaid 135KB lazy）发挥关键作用——前版的修正给后版兜了底。
