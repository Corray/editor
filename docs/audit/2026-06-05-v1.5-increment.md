## 1. 范围与方法

## 2. 干净项（正向比对）

- **SW + Workbox runtime 自托管**：generateSW 内联 Workbox（无 CDN），CSP `script-src 'self'` **不放宽**；新增 `manifest-src`/`worker-src 'self'` 收口。安全红线守住
- **首屏闸守住**：PWA 不进首屏 runtime（仅 workbox-window +0.84KB → 78.18KB gz <150）；SW/Workbox/图标均非首屏
- **离线正确性 e2e 实证**：pwa project（build+preview 真 SW）4 场景全过——离线 reload 可编辑 / 离线持久化 / **离线 mermaid+katex 渲染**（chunk precached）/ console 干净
- **toast action 向后兼容**：3-arg 调用行为不变（UT-TOAST-010 验证）；action toast 持久不自动消失（更新提示语义对）
- **register 解耦虚拟模块**：DI 设计（registerSW 作参数）→ 无需 `virtual:pwa-register` 即可单测（UT-PWA-001~003）
- **M8 横切隔离**：不动 M1-M7 业务 / 持久化 / 渲染管线
- **更新策略不打断**：registerType:prompt（非 autoUpdate），用户点刷新才换版

## 4. 盲点声明

- **未实测真实部署更新**：onNeedRefresh→toast→updateSW 链路靠单测 mock；真实"部署新版触发 SW waiting"未端到端跑（线上眼验可补：部署 v0.6.0 后再推一次小改，看是否弹更新提示）
- **离线 e2e 仅 chromium**（pwa project 用 Desktop Chrome）；webkit 的 SW 行为差异未覆盖
- **precache 3.7MB 未实测移动端首次访问流量体感**（静态推断）
- 自审自己代码（无第二人）

## 5. 结论

v1.5 增量 **1 条 MEDIUM（F-V15-1 precache 3.7MB）+ 4 LOW**。安全面（SW/Workbox 自托管 + CSP 不放宽）守住、首屏闸守住、离线正确性 e2e 实证。**F-V15-1 是 accept 的 D2(a)「含懒加载 chunk」的放大后果**——非违规、应用功能正确，但对轻量编辑器/移动端场景的 3.7MB 静默 precache 值得在 tag v0.6.0 前定夺（修：重 diagram 子 chunk 改 runtimeCaching）。按 F-V11-1（MEDIUM tag 前修）先例，建议先定夺再 tag。

**跨版本一致性**：延续"安全敏感面降风险"（SW 自托管不放宽 CSP，类比 v1.3 KaTeX output:html / v1.4 mermaid strict）；F-V13-4（眼验 console 干净）已落实为 E2E-v15-006 固定项。
