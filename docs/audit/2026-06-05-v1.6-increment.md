## 1. 范围与方法

## 2. 干净项（正向比对）

- **迁移数据安全（重点）**：3 路迁移（`kv/document` v1.1 / `localStorage` v1.0 直跳 / 新用户）+ **先写后删幂等**（沿用 v1.1 范式）+ idempotent（documents 非空跳过）；unit 13 + e2e 双引擎实证。**v1.0 直跳 v1.6 盖空 case 被实现期 e2e（E2E-v11-001）捕获并补兜底路** → 谱系 ls→kv→documents 全覆盖
- **单 store 单写者**：仅 M9 写 documents；M3 退化为状态机经 `saveActiveText` 委托（无双写）
- **不变量守住**：永远 ≥1 篇（remove-last 自动建空）；activeId 必有效（删 active 切最新）；no-op-save 防切换 spurious bump（UT 验证）
- **切换 flush**：switchTo/create 前 `saveActiveText(getEditorText())` flush 当前 → 不丢未存盘编辑（E2E-v16-002 实证）
- **ID 合规**：`D_<uuid>` 顶级前缀 + `EntityIdPrefixes` 集中常量（arch-constraints §6）
- **涟漪不毁数据**：import/open-shared → 新建文档（不覆盖当前；E2E-v16-share-new/import-new 验证列表 +1）
- **M9 可测**：DI 设计（now/setEditorText/getEditorText 注入）→ 迁移/CRUD 纯逻辑单测（fake-indexeddb）
- **附带修 FOUC**：async bootstrap 延迟主题 → applyInitialTheme 同步先于 await（ac6 双引擎验证，深色不闪白）

## 3. 发现（全 LOW）

| 编号 | 单元 | 描述 | severity |

## 4. 盲点声明

- **迁移仅测有限内容**（H1/首行/空）；超大单 doc 迁移、迁移中途崩溃恢复未专门测（先写后删理论上安全，未注入崩溃）
- F-V16-1 切换竞态靠 no-op guard 兜，未专门写"快速连续切换 + pending debounce"压力测试
- 多 tab / 大量文档 perf 静态推断，未实测
- 离线多文档（AC-v16-8）未单列 e2e（多文档同 IDB，PWA precache 不含用户数据，间接推断不退化）
- 自审自己代码（L3 大改尤需第二人，无）

## 5. 结论

v1.6 增量**无 critical/high/medium**（**最大版无 MEDIUM**）。持久化根基单→多的最大风险（迁移数据丢失）经**复用 v1.1 先写后删幂等范式 + 单写者纪律 + 3 路迁移测试**控住，且 v1.0 直跳盖空 case 被实现期 e2e 主动捕获补强。5 条 LOW（切换竞态 info / 无重命名 / 降级单文档 / 多 tab / 列表规模）deferred v1.6.x，不阻塞 tag v0.7.0。

**跨版本一致性**：第三次迁移复用 v1.1 范式（ls→kv→documents 谱系连续）；async bootstrap 的 FOUC 是 v1.5（PWA）以来 bootstrap 渐重的副作用，本版修正；"实现期 e2e 捕获迁移盖空 case"印证 spec-to-code-flow 的 Check 环节价值（测试计划家族枚举 → 实测兜出设计未尽）。
