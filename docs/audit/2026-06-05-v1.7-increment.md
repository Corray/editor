## 1. 范围与方法

增量：M2 pipeline（source_line core rule + render ADD_ATTR）/ M10 `createScrollSync` / EditorArea+PreviewArea ref / AppShell createEffect / M4 copyHtml strip / `#root` 布局。方法：逐文件重读 + 对齐共识 v1.7 / ADR-011 / **ADR-002 sanitize 红线** / 安全，对抗视角找 XSS 放行扩面 / 反馈环 / 布局回归 / 映射降级。

## 2. 干净项（正向比对）

- **ADD_ATTR 不破红线 + XSS 复验**：仅放行 `data-source-line`（惰性数字属性，无 url/事件/执行语义）；标签/事件/url sanitize 严格不变。AC-v17-5 发布门槛：unit（`<script>`/`onerror`/`javascript:` 仍剥离 + 仅 data-source-line 放行）+ e2e 双引擎（恶意输入无 alert/script/onerror，data-source-line 在安全块放行）
- **反馈环防护**：syncing 标志 + rAF 清窗，被驱动方 scroll 内忽略 → e2e 实证无抖动（edSettled 稳定）
- **桌面 only + 卸载干净**：createEffect viewport==='desktop' 才挂；onCleanup dispose；移动单栏不启用（E2E-v17-004 无报错）
- **export 干净**：copyHtml 剥离 data-source-line（内部属性不泄漏到用户复制 HTML / UT 验证）
- **双向映射实证**：editor→preview + preview→editor e2e 双引擎过；source-line 抗块高差异（非比例漂移）
- **无新依赖 / 无持久化变更**

## 4. 盲点声明

- **XSS 仅测已知向量 + data-source-line 注入面**；未穷举所有 ADD_ATTR 绕过尝试（但 data-source-line 惰性，面极小）
- 映射精度（块内偏移 F-V17-2 / 软换行 F-V17-3）未做像素级断言（e2e 只验方向 + 非 0）
- 布局改动（F-V17-1）full e2e 过，但未在多种真实屏尺寸 / 浏览器缩放下眼验
- 反馈环高频压力（F-V17-4）未实测
- 自审自己代码（无第二人）

## 5. 结论

v1.7 增量**无 critical/high/medium**。安全敏感点（动 sanitize ADD_ATTR）经"仅放行惰性属性 + XSS 复验双引擎"控住，ADR-002 红线（标签/事件/url）不放宽，AC-v17-5 达成。4 条 LOW（布局 info / 块顶对齐 / 软换行映射偏差 / 反馈环窗口）deferred，不阻塞 tag v0.8.0。

**跨版本一致性**：动 sanitize 配置 → XSS 复验，延续 v1.3/v1.4 安全门槛模式；**实现期 live MCP 探针定位"面板不滚"布局根因**，类比 v1.6"实现期 e2e 兜出迁移盖空 case" / v1.6 FOUC——bootstrap/布局渐复杂的潜伏问题靠实测暴露。data-source-line 过 sanitize 用 ADD_ATTR（而非 v1.4 mermaid 的 textContent 绕路），因行号须在属性上供 JS 读 —— 两种"过 sanitize"手法按需选择。
