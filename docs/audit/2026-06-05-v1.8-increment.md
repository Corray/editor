## 1. 范围与方法

增量：`m9-doc-manager`（store DocRecord +titleManual / manager rename + saveActiveText 旁路 + query 过滤）/ DocList（搜索框 + 内联重命名）/ i18n。方法：逐文件重读 + 对齐共识 v1.8 / ADR-012 / data-model v1.8，对抗视角找标题锁失效 / 搜索漏过滤 / 重命名取消语义 / 旧记录兼容 / XSS。

## 2. 干净项（正向比对）

- **titleManual 锁解 F-V16-2**：rename→titleManual=true→saveActiveText 不再 deriveTitle（UT-M9-rename-lock + E2E-v18-002 双引擎实证"改名后编辑不覆盖"）
- **空重命名回退**：rename('')→titleManual=false+deriveTitle（UT-M9-rename-empty）
- **搜索 title+content**：query 匹配标题或正文（records 含 text，无额外 IO；UT-M9-search 验内容命中 + 清空恢复）
- **旧记录兼容无迁移**：DocRecord +titleManual 可选，IndexedDB schemaless，旧记录 undefined=falsy=自动（UT-M9-legacy-autotitle / DB 版本不升 / AC-v18-6）
- **取消语义正确**：Esc 不提交（editingId 守 onBlur 防 unmount-blur 误提交，E2E-v18-004 双引擎）
- **无 XSS 面**：重命名输入作标题**纯文本**显示（span textContent / input value），不 innerHTML、不动 sanitize
- **无 DB 升级 / 无新依赖 / 不动渲染/持久化根基**

## 4. 盲点声明

- **实现期 2 bug 靠测试捕获**（query TDZ 全测试挂 / Esc-unmount-blur 误提交）——说明 reactive 信号顺序 + 卸载副作用是易错点，已修 + 测试守住；但同类（信号声明序 / unmount 副作用）可能在别处潜伏未覆盖
- 搜索 perf（F-V18-1）/ 大量命中（F-V18-2）静态推断未压测
- 内联重命名 IME（中文输入法）合成中按 Enter 的行为未专门测（中文重命名常见场景）
- 自审自己代码（无第二人）

## 5. 结论

v1.8 增量**无 critical/high/medium**。F-V16-2（v1.6 遗留 LOW）**resolved**。无 DB 升级、旧记录兼容、无 XSS 面（重命名纯文本）。4 条 LOW（搜索 perf / 不跳转 / 双击发现性 / 搜索-active 不一致）deferred。

**跨版本一致性**：titleManual 用 IndexedDB schemaless 加可选字段（无迁移）——与 v1.6 加字段同手法；实现期 2 bug 靠 unit+e2e 捕获，延续"测试兜出实现细节"模式（v1.6 迁移盖空 / v1.7 布局 / v1.7 fill-scroll 断言失效）。**IME 重命名是诚实盲点**（中文场景未测）。
