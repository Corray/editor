## 2. 实现期发现并处置

| 发现 | 处置 |
|------|------|
| 帮助面板 Esc 在 webkit 失效：WebKit/Safari 点按钮**不转移焦点**，keydown 从 body 冒泡不经过 `<main>` → main 级 onKeyDown 收不到 | 改 window 级监听（与焦点解耦），e2e 双引擎复验过。范式记录：**模态/全局快捷键一律 window 级**，不依赖容器冒泡 |
| 全量回归首跑 7 个既有套件失败（27.6 分钟，正常 ~3）| 定性 = 系统负载超时非回归：空载复跑失败套件 26/26 过 + 全量 131/131 过。教训：**异常时长的测试结果先查负载再查代码** |
| TDZ 家族预防：v2.4 scroll effect 初版引用后声明的 editorEl | 实现期自查移到声明后（v1.8 query TDZ 先例）|
