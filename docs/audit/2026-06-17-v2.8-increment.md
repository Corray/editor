## 2. Tab 冲突分流（本版核心审查点）

- **三级优先级**：`allowTabOnce`（a11y 逃逸）→ `tableCellNav`（表格行）→ `indentSelection`（v2.4 缺省）。互斥清晰，e2e AC21-4 实证非表格行仍走缩进，无回归 ✅
- 判定启发式 `isTableRow = trim().startsWith('|')`——简单稳健；非 `|` 起头表格变体不支持（文档化限制，可接受）

## 3. 安全面

- 插入纯 Markdown 表格语法进 textarea value → 渲染走既有 DOMPurify；不动 sanitize ✅
- tableCells 纯文本 `|` 位置切分，无外部输入面 ✅
