## 2. 完整性保障（本版核心）

- **编译期强制**：`enUSDict: Record<DictKey, string>` —— 漏任一 key = tsc 报错，强于运行时白名单校验（张力 A 根治）
- CT-I18N-1 运行时再验 key 集相等（双保险）+ CT-I18N-3 占位符 `{n}`/`{m}` 两侧保留
