## 2. 安全面（本版核心审查点）

- **sanitize 不放宽**（探针前置验 + 实测）：checkbox `<input type=checkbox>` 经 render() 默认 DOMPurify 放行；`onclick`/`onerror`/`<script>` 默认剥离；ADD_ATTR 仍仅 data-source-line（**ADR-002 红线零改动**）
- renderer 规则输出受信（不受 html:false 影响，同 installMermaidFence）；checkbox 是渲染产物非用户 HTML
- 点击回写走 `state.setText`（纯文本翻转），不 innerHTML；toggleTaskAtLine 正则锚定行首列表标记，无注入面

## 3. 实现要点

- 复用 v1.7 `data-source-line`：checkbox 直接携带源行号 → 点击委托零 DOM 爬树
- 单一数据源：preventDefault 撤销原生 toggle，真值由源文重渲染驱动（不靠 DOM 态，避免双向不一致）
- core rule `after('inline')`：在 inline 解析后改 children，base+katex 渲染器均装（同既有范式）
