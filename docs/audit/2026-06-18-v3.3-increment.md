## 2. 安全 + 边界（本版核心）

- **识别边界严**：仅 `startLine===0` + 首行 `---` + 有闭合 `---`；文中 `---`/无闭合 → 落 hr（不吞全文）——CT-FM-2/3 实证，无误识别面
- **sanitize 不放宽**：值经 `md.utils.escapeHtml` + render() 默认 DOMPurify；ADD_ATTR 仍仅 data-source-line（ADR-002 红线不动）；XSS unit+e2e 双引擎验
- 无新依赖（自定义 block rule，不引 js-yaml → 无 YAML 解析面 + 无体积）
