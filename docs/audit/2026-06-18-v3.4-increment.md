## 2. 双实例同步正确性（本版核心）

- baseMd + katexMd 双实例 × 扩展插件 mutate → **每实例恰好应用一次**（applyExtensions）：
  - 扩展先载 → applyExtensions(baseMd) + katexMd 若存在
  - katex 后载 → ensureKatex 末尾 applyExtensions(katexMd)
  - 两加载器对称协同，无双注册（CT-EXT 全过 + e2e katex×ext 共存隐含验）
- 懒加载 hasExtension 启发式（katex hasMath 范式）；首屏不含（size 闸守）

## 3. 安全面

- emoji 渲染 Unicode 字符（安全）；footnote `<sup>/<a href=#fn>/<section>/<ol>`、sub/sup `<sub>/<sup>` 均 DOMPurify 默认放行（标准标签）；经 render() 既有 sanitize，ADD_ATTR 不放宽（ADR-002）；XSS unit+e2e 双引擎验 ✅
