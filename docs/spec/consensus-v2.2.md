## 1. 动机与范围

长文档（v2.1 实测基线 374KB/5000 行级别可正常编辑）缺导航手段——找某节只能 Cmd+F 或手滚。本版给标题层级一个可点击的大纲。

**范围（仅）：** 从文档标题生成大纲列表 + 点击跳转编辑器对应位置（滚动同步自然联动预览）。
**不在本次：** 大纲内拖拽重排章节 / 折叠子级 / 当前位置随滚动高亮（见 TBD-v22-4 反向确认）/ 预览端独立 TOC 渲染（`[[toc]]` 语法插件）。

---

## 2. 张力

### 张力 A — 数据源：源文解析 vs 预览 DOM
- 预览 DOM 读 h1-h6（带 data-source-line，语义与渲染完全一致）——但依赖 preview 已挂载+渲染完（大文档防抖 120ms 滞后；移动端编辑 tab 时 preview 根本不在 DOM）
- 源文 regex 解析 ATX 标题（`^#{1,6} `）——独立于渲染时序，移动端可用；需跳过 fenced code block 内的伪标题；setext 标题（下划线式）不支持

### 张力 B — 第四栏放哪
桌面已是 [DocList sidebar | 编辑 | 预览] 三栏，TOC 常驻第四栏太挤。候选：sidebar 分区复用 / header 按钮浮层 / 预览内浮动。

## 3. 待确认项（TBD-v22-x）

### TBD-v22-1 — TOC 入口与布局〔需你拍板：UX〕
- **(a) 左 sidebar 下半分区**：DocList 占上半，大纲占下半（文档无标题时显空态提示）；移动端 v2.2 不做（桌面 only，M10 滚动同步先例）〔AI 倾向：常驻可见、不加 header 噪音；TOC 本是长文档功能，移动速记场景边缘〕
- (b) header「大纲」按钮 → 浮层 dropdown，点击跳转后收起（移动端也可用）
- (c) 预览面板内右上浮动 mini-TOC

### TBD-v22-2 — 数据源
- **(a) 源文 ATX regex 解析**（跳过 fenced code block；setext 不支持，文档化）〔AI 倾向：不依赖渲染时序、移动端可用、实现薄；走 deferred 信号同 wordcount 不进输入路径〕
- (b) 预览 DOM 读 h1-h6（语义全对但受防抖/挂载时序约束）

### TBD-v22-3 — 跳转行为
- **(a) 编辑器滚动到行（行号×行高估算居中）+ 光标置行首**；预览靠既有 M10 滚动同步自然联动〔AI 倾向：复用 v1.7 链路零新协议〕
- (b) 编辑器和预览各自显式跳（绕过 scroll sync，多一条预览定位协议）

### TBD-v22-4 — 层级与高亮
- **(a) h1-h6 全层级缩进展示，无折叠、无当前位置高亮**〔AI 倾向：高亮需 scroll 监听+反向映射，复杂度 ↑ 收益存疑，defer 观察反馈〕
- (b) 加当前位置随滚动高亮

## 5. 验收条件（v2.2 新增 AC，待 test-plan 细化）

- AC-v22-1：含 h1-h6 的文档 → 大纲按层级缩进列出全部标题（顺序与源文一致）
- AC-v22-2：fenced code block 内的 `# 伪标题` 不进大纲
- AC-v22-3：点击大纲项 → 编辑器滚动到该标题行附近且光标落该行行首；桌面预览随滚动同步联动
- AC-v22-4：编辑中新增/删除标题 → 大纲随之更新（deferred 节奏，不阻塞输入路径）
- AC-v22-5：无标题文档 → 大纲区显空态提示，不渲染空列表
- AC-v22-6：切换文档 → 大纲立即换为新文档的标题
- AC-v22-7：既有行为零回归（DocList 交互、查找/快捷键、滚动同步、移动端单栏）

> 无安全门槛：标题文本纯文本渲染进大纲（textContent，不 innerHTML），无新 XSS 面；不动 sanitize。
