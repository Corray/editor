## 1. 动机与范围

Markdown 表格手写痛（对齐管道符、补分隔行）。本版给「插入表格」+「单元格间快速跳转」。

**范围（仅）：** 插入表格模板（工具栏）+ 表格行内 Tab 单元格导航。
**不在本次：** 表格可视化编辑器 / 列宽对齐美化 / 增删列按钮 / 单元格合并（Markdown 无此语义）。

---

## 2. 张力

### 张力 A — Tab 已被 v2.4 缩进占用（核心冲突）
v2.4 拦 Tab 做缩进。表格单元格导航也想用 Tab（编辑器惯例）。需按**光标是否在表格行**分流：表格行（`| … |`）内 Tab = 跳下一单元格；非表格行 = 维持 v2.4 缩进。判定纯文本启发式（当前行 trim 以 `|` 起头/含 `|`）。

### 张力 B — textarea 表格编辑的根本限制
无列宽自动对齐（等宽字体下管道符不齐）；单元格导航靠定位下一个 `|` 后的文本区间。MVP 取舍：功能性导航优先，不做对齐美化（共识范围外）。

## 3. 待确认项（TBD-v28-x）

### TBD-v28-1 — 插入表格入口与模板〔需你拍板〕
- **(a) 工具栏第 9 按钮「⊞ 表格」→ 插入 2 列模板**（表头行 + 分隔行 + 1 数据行，占位 `列1/列2/单元格`）〔AI 倾向：与 v2.7 工具栏一致入口〕
- (b) 插入时弹 prompt 问行列数（多一步交互）
- (c) 固定 3 列模板

### TBD-v28-2 — Tab 单元格导航〔需你拍板：是否承担 Tab 冲突〕
- **(a) 表格行内 Tab → 跳下一单元格（光标选中该单元格文本）；行末单元格 Tab → 跳下一行首单元格（无下一行则新增一行）；Shift+Tab 反向。非表格行维持 v2.4 缩进**〔AI 倾向：表格编辑核心价值〕
- (b) 不做单元格导航（仅插入模板，Tab 永远缩进——零冲突，但表格编辑弱）

### TBD-v28-3 — 表格行判定启发式
- **(a) 当前行 trim 后以 `|` 起头 视为表格行**（简单稳健；非 `|` 起头的表格变体不支持，文档化）〔AI 倾向〕
- (b) 更宽松（含 `|` 即判）→ 普通含管道符文本误判风险

## 5. 验收条件（AC-v28-x）

- AC-v28-1：工具栏 表格按钮 → 插入 2 列模板（表头+分隔+数据行），光标落首单元格
- AC-v28-2：表格行内 Tab → 光标跳下一单元格并选中其文本；Shift+Tab 反向
- AC-v28-3：行末单元格 Tab → 跳下一行首单元格；末行末单元格 Tab → 新增一行（同列数空单元格）
- AC-v28-4：非表格行 Tab → 维持 v2.4 缩进（零回归）
- AC-v28-5：插入/导航 Cmd+Z 可撤销（复用 replaceRange / AC-v21-7）
- AC-v28-6：既有零回归（缩进/列表延续/工具栏/快捷键）

> 无安全面：插入文本纯 Markdown 表格语法进 textarea，渲染走既有 DOMPurify；不动 sanitize。
