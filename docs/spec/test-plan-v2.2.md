## 2. 家族维度（设计期枚举）

- **解析族**：`h1~h6 × 前导空格(0~3 收 / ≥4 缩进代码不收) × 尾随闭合 #(剥离) × # 后无内容(不收) × fenced(``` 与 ~~~ × 嵌套伪标题排除 × 未闭合 fence 到文末) × inline code 行(非 fence 不误判) × CRLF 容错`
- **跳转族**：`首标题(顶部) × 深处标题(scrollTop>0) × 光标 offset 落行首 × 桌面预览联动`
- **刷新族**：`输入新增标题 → 大纲出现 × 删除 → 消失 × 切换文档 → 全量换 × 无标题 → 空态`
